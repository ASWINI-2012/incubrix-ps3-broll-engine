# Local demo footage

The legacy `earth-from-iss-preview.mp4` file is retained for provenance only and is no longer selected by demo mode. Frame inspection found black title-card sections and unrelated burned-in presentation text, so it is unsuitable as generic or scene-matched B-roll.

NASA's [Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) say NASA content is generally not subject to U.S. copyright, but note third-party copyrights, privacy/publicity rights, restrictions around identifiable NASA personnel, and endorsement limits. NASA should be acknowledged as the source. Review the guidance and the source item before external or commercial use; the project does not establish rights for every depicted element.

Demo mode searches validated local catalogue media without an API key. A missing relevant scene is reported as an error. Configure a licensed provider for online scene-matched stock search.
